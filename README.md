# yeodeun-privacy

The privacy policy page for the game Eighty Choices (여든 번의 선택), by Noeul Games.

## What it is

A one-page static site published with GitHub Pages: https://silverleopard12.github.io/yeodeun-privacy/

`index.html` is the policy itself. It is a single HTML file with Korean and English sections side by side, in light and dark colors that follow the reader's device. `.nojekyll` tells GitHub Pages to publish the file as it is.

## What the policy says

- Effective date: October 14, 2026
- Developer: Noeul Games (노을)
- The game does not collect personal data. It has no account or sign-in, works offline, and has no ads, analytics or third-party SDKs.
- Game records and settings stay on the player's device. The bug report is shown in full on the screen and leaves the device only when the player sends it.
- Contact: noeulgames@gmail.com

Read the page itself for the exact wording; this list is only a summary.

## Editing the policy

To change the policy, edit `index.html` and update the effective date in the text. There is no build step and nothing to install: open the file in a browser to preview it. Changes go live when they reach the branch that GitHub Pages publishes.
