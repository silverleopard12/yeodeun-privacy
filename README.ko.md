# yeodeun-privacy

노을 게임즈(Noeul Games)의 게임 「여든 번의 선택」(영문 제목 Eighty Choices)의 개인정보 처리방침 페이지.

## 이 레포는

GitHub Pages로 올린 한 장짜리 정적 페이지다: https://silverleopard12.github.io/yeodeun-privacy/

`index.html`이 처리방침 그 자체다. 한국어와 영어 두 부분이 나란히 들어 있는 HTML 한 파일이고, 읽는 기기의 밝은/어두운 설정에 색이 따라간다. `.nojekyll`은 GitHub Pages가 이 파일을 그대로 올리게 한다.

## 처리방침 내용

- 시행일: 2026년 10월 14일
- 개발자: Noeul Games(노을)
- 게임은 개인정보를 수집하지 않는다. 회원 가입·로그인이 없고, 인터넷 없이 돌아가며, 광고·분석 도구·제3자 SDK가 없다.
- 게임 기록과 설정은 플레이어의 기기에만 남는다. 버그 알리기 보고서는 화면에 그대로 보여 주고, 플레이어가 직접 보낼 때만 기기를 떠난다.
- 문의: noeulgames@gmail.com

정확한 문구는 페이지에서 직접 읽을 것. 이 목록은 요약일 뿐이다.

## 처리방침 고치기

처리방침을 바꾸려면 `index.html`을 고치고 글 속의 시행일도 함께 바꾼다. 빌드 단계도 설치할 것도 없다. 브라우저로 파일을 열어 미리 볼 수 있다. 고친 내용은 GitHub Pages가 올리는 브랜치에 들어가면 공개된다.
